# Adding Database to the project

- the db can live within the server, or maybe outside the server too
- here, we are using MongoDB through an online service called MongoDB Atlas
- In our project we are going to use an ORM (Object Relational Mapper), which helps to connect and talk to our MongoDB, easily (better syntax)

1. Install mongoose with npm
2. make a db-connector file in db directory and import mongoose
```js
const connectDB = async () => {
  try {
    await mongoose.connect(process.env.MONGO_URI);
    console.log("MongoDB Connected Successfully!");
  } catch(error) {
    console.error("MongoDB connection Error ", error);
    process.exit(1);
  }
}
```
- the MONGO_URI (uniform resource identifier) is a standard connection sting, that is used to connect to MongoDB Database
3. now export the function with default
4. if needed
  - make a new user and password (avoid special characters in password)
  - go to the clusters and connect, choose compass
  - inside compass copy the connection string
5. inside the .env copy the connection string to MONGO_URI and change the username and password..

- now the mongoose.connect(...) thing works

- In the index.js file, import the connectDB function.
  - with calling the function use .then and .catch blocks
  - inside .then(()=>{app.listen(...)}) and then catch(()=>{console.error(...)})
  - and exit the code with process.exit(1);

## Writing Models and Schema
- in the db directory make a file user.model.js where the user model and schema is defined
```js
import mongoose, { Schema } from "mongoose";

const userSchema = new Schema({
  avatar: {
    type: {
      url: String, // where the image is stored in db
      localPath: String, // where the image is stored in the locally
    },
    default: {
      url: `https://placehold.co/200x200`,
      localPath: "",
    }
  },
  username: {
    type: String,
    required: true,
    unique: true,
    lowercase: true,
    trim: true,
    index: true
  },
  email: {
    type: String,
    required: true,
    unique: true,
    trim: true
  },
  fullname: {
    type: String,
    trim: true,
  },
  password: {
    type: String,
    required: [true, "Password is Required"]
  },
  isEmailVerified: {
    type: Boolean,
    default: false,
  },
  refreshToken: {
    type: String
  },
  forgotPasswordToken: {
    type: String
  },
  forgotPasswordExpiry: {
    type: Date
  },
  emailVerificationToken: {
    type: String
  },
  emailVerificationExpiry: {
    type: Date
  }
}, {
  timestamps: true, // gives 2 more fields, createdAt and updatedAt
});

mongoose.model("User", userSchema);
export const User = mongoose.model("User", userSchema);
```

- mongoose.model("User", userSchema) -- directs to make a model "User", that follows userSchema
- then export it as User
- the mongoose schema, allows us to write methods and also hooks

#### Methods
- methods are functions that belong to a document 
```js
userSchema.methods.isPasswordCorrect = async function(password) {
  return await bcrypt.compare(password, this.password);
};
```
- this is put with the userSchema, and every userSchema gets that method
- methods are the actions that every user can perform

#### Hooks
- Hooks let u run code automatically at certain points of the document's lifecycle
- eg.
  - before/after save
  - before/after delete
  - before/after update

- before saving (pre-hook)
```js
userSchema.pre("save", async function () {
  console.log("About to save...");
});
```
- so before saving to the database, that operation is run
- the password hashing code
```js
userSchema.pre("save", async function () {
  if (!this.isModified("password")) return;

  this.password = await bcrypt.hash(this.password, 10);
});
```
